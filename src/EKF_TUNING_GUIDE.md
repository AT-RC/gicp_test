# EKF 滤波多传感器融合调参实战指南

本指南专为 **强化学习四足机器狗 + Mid360 (Point-LIO) + Small GICP 重定位** 的双 EKF 融合架构编写。

> **核心原则**：永远不要在真狗实盘运行中盲调卡尔曼滤波！请务必采用 **“实车录包 -> 离线回放 -> 观测曲线 -> 修改参数”** 的闭环工作流。

---
**记得sudo apt install ros-humble-robot-localization**
## 阶段一：数据采集（实机录包）

在真狗上开启你的所有传感器和定位算法，让狗在具有代表性的场地上完整跑一圈（包含平地、急转弯、以及可能发生打滑或特征稀疏的区域）。

在实机跑动期间，在终端执行以下命令录制底层原始数据：
```bash
ros2 bag record /odometry /livox/imu /gicp_pose /tf /tf_static -o dog_ekf_tuning_bag
```
*注：只录制融合所需的骨干话题，不要录制庞大的 `/cloud_registered` 点云，以免电脑卡死。*

---

## 阶段二：回放与可视化（调参环境搭建）

把录好的包拷到电脑上（或者直接在工控机上操作）。此时你不需要开启真实的传感器，只需要运行 EKF 节点：

1. **修改 Launch 文件**：在 `bringup_ekf.launch.py` 中，把启动雷达、Point-LIO 和 GICP 的部分注释掉，**只保留** `tf_to_pose_node`、`ekf_local_node`、`ekf_global_node` 和 `rviz_node`。
2. **启动 EKF 核心**：运行上述精简后的 Launch。
3. **回放数据**：在另一个终端循环播放数据包：
   ```bash
   ros2 bag play dog_ekf_tuning_bag --loop
   ```
4. **曲线可视化**：打开 `PlotJuggler`（强烈推荐）或 `rqt_plot`，将以下两条曲线画在同一个折线图里进行对比：
   - **原始绝对测量**：`/gicp_pose/pose/pose/position/x` (带有锯齿和低频跳变)
   - **滤波平滑输出**：`map -> base_link` TF 坐标的平移 X 值 (或者 `ekf_global` 最终输出的 `odometry/global` 的 X 值)

---

## 阶段三：核心参数博弈（跷跷板原理）

你现在拥有了上帝视角。看着两条曲线，修改以下两个核心参数。**每次修改后，重新启动 Launch 文件，观察曲线的瞬时变化。**

### 旋钮 A：调节 GICP 的“信任度”
**修改位置**：`src/bring_up/scripts/tf_to_pose.py` 约第 43 行的 `covariance` 对角线前三项。
**默认值**：`0.01` (相当于标准差 10 厘米)。

* **症状 1：轨迹发抖 (Jitter)**
  * **表现**：滤波输出的曲线跟着 GICP 的高频锯齿一起上下抖动，导致四足狗在原地发颤。
  * **原因**：EKF 过于信任有网格量化误差的 GICP。
  * **操作**：**调大** GICP 协方差。将 `0.01` 改为 `0.1` 甚至 `0.5`。迫使 EKF 去相信顺滑的 Point-LIO。
* **症状 2：修正迟缓 (Lagging)**
  * **表现**：过弯或大漂移发生后，GICP 的曲线已经瞬间跳到了正确位置，但滤波曲线像拉着牛车一样，过了 2~3 秒才缓慢“滑”过去重合。
  * **原因**：EKF 觉得 GICP 不太可信，非要死守着发散的轮推。
  * **操作**：**调小** GICP 协方差。将 `0.01` 改为 `0.001`。让 EKF 一收到绝对坐标就迅速贴合。

### 旋钮 B：调节系统整体的“敏捷度 / 神经质”
**修改位置**：`src/bring_up/config/ekf.yaml`，可以手动添加 `process_noise_covariance` 矩阵对角线。
**默认值**：`robot_localization` 内部默认值通常约为 `0.05` 级别。

* **症状 3：全盘迟钝**
  * **表现**：不管你把 GICP 的方差设得多小，系统反应就是慢半拍。
  * **原因**：系统自身的过程噪声设得太小，导致系统过于自信，认为自己不可能发散。
  * **操作**：在 `ekf.yaml` 的对应 EKF 节点下，把过程噪声的对角线整体放大 10 倍。系统瞬间会变得毫无安全感，从而极速贴合外部传感器。

## 终极目标图景

经过上述调参，你在 `PlotJuggler` 里应该看到一幅完美的图景：
**红线（滤波后）犹如一条极其优雅平滑的丝带，从头到尾完美地穿插在蓝线（GICP 测量锯齿）的正中间地带。既不被它带偏抽搐，也不落后它超过半秒的反应时间。**

此时，将这套参数固化，写到真实机器狗中，你的底盘控制算法将获得史无前例的稳定性体验！
